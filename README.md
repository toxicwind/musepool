# musepool

Async-aware process pool with mutative scheduling, CDN-aware package resolution, and sovereign-pi integration hooks.

## Features
- CDN-aware resolution (Alibaba, Tsinghua, PyPI)
- Mutative scheduling
- Sovereign-pi hooks
- Python 3.12+ primary, 3.11/3.8 AST fallback

## Install
```bash
pip install musepool
```
